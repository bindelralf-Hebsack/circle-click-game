# Circle Click Challenge

Ein einfaches Spiel in Python mit `pygame`.

## Spielidee
- Ein Kreis bewegt sich zufällig auf dem Bildschirm.
- Du musst mit der Maus den Kreis verfolgen.
- Wenn die Maus im Kreis ist und du mit der linken Maustaste klickst, bekommst du einen Punkt.
- Mit jedem Treffer wird der Kreis schneller.
- Wenn du 3 Klicks außerhalb des Kreises machst, ist das Spiel vorbei.
- Am Ende wird deine Punktzahl angezeigt.

## Voraussetzungen
- Python 3 installiert
- `pygame` installiert

## Installation
```bash
pip install -r requirements.txt
```

## Starten
```bash
python main.py
```

## Spielsteuerung
- Maus bewegen: Kreis verfolgen
- Linke Maustaste: Kreis treffen
- Ziel: So viele Punkte wie möglich erreichen
